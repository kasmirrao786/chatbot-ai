One script tag — the entire integration a tenant's site needs. The key isn't a true secret since it ships in the page source; it exists for per-tenant rate limits and revocation. Regenerating invalidates the old key immediately.
Branding / theme
Overrides the widget's default colors — borders, message backgrounds, soft text. A few elements aren't wired to this yet.
Custom CSS / JS
⚠️ This runs in every visitor's browser on this tenant's site, unsandboxed. Custom JS is exactly as powerful as a <script> tag the tenant could add to their own page themselves — it can read/modify the page, make network requests, and read cookies available to that page. It is not reviewed, sanitized, or restricted. Only paste code you trust, and treat access to this tab like access to the tenant's own site source. Custom CSS is lower-risk but still applies site-wide wherever the widget is embedded, not just inside the chat window.

Field name is the internal key. Description is what the bot asks for and what extraction uses to parse the reply.
Real calendar availability (raw JSON): set tenant_meta.booking.availability.calendarCheckUrl to an n8n webhook (see deploy/n8n/workflows/visa-assistant-calendar-check.json) to filter booked slots. Unset keeps business-hours-only.
To disable booking entirely, use the Automations tab. The bot then falls back to office contact info, or to tenant_meta.contactFallback if set, e.g. { "text": "Reach out via our contact page", "url": "https://example.com/contact" }.
Serviced countries
Hard boundary — the bot refuses visa/process questions about countries not listed here rather than guessing. Leave empty to disable this check.
